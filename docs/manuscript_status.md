# Manuscript status

The authored paper, references, and graphical abstract live in
`docs/manuscript/`. The native builder reads those numbered sections and
emits an MDKV container with primary and references tracks. Pinned Template
stages render and validate the standalone PDF and HTML from the same source.

The archived PDF, container, and bundled outputs remain under `paper/`.
See [publication build instructions](publication.md) for fresh local output.
